# 洛谷档案馆帮助中心

欢迎！

这里是 [洛谷档案馆](https://www.luogu.ac.cn) 的帮助中心，一个非洛谷官方的开源项目，旨在实现一些便捷的功能，方便洛谷用户的使用。

:::: details 本项目目前实现的功能

- 文档，剪贴板，陶片放逐保存；

- 用户多项历史保存；

- 用户犇犇保存；

- 讨论区保存（目前仅支持非题目板）；

- 插件广场；

- 题解修，方便地进行题解格式的修正；

- ~~比赛历史与比赛等级分预估~~；[^1]

- ~~题目保存，可显示能够提交题解的题目~~；[^1]

- 更多更多……

::::

[^1]: 曾经实现过，但如今因 [洛谷官方要求](https://luogu.ac.cn/discuss/1368593)，这些内容因无法在新规下实现，已被暂时移除。

如果你想快速了解这个项目如何使用，可以读 [快速上手](/quick-start)，遇到问题可以查看 [常见问题](/faq)。

作为用户，如果你想使用站内插件，建议阅读 [插件使用须知](/plugin/usage)。

作为开发者，上传插件前请阅读 [上传须知](/plugin/upload)，想让插件收到推荐，获得更多曝光，请阅读[推荐须知](/plugin/recommend)。

对于项目的其他政策，见 [隐私协议](/policies/privacy)、[免责声明](/policies/disclaimer) 和 [数据移除政策](/policies/data-removal)。
