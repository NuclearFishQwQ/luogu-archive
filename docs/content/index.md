# 洛谷档案馆帮助中心

欢迎！

这里是 [洛谷档案馆](https://www.luogu.ac.cn) 的帮助中心，一个非洛谷官方的开源项目，旨在实现一些便捷的功能，方便洛谷用户的使用。

截止目前（2026.10.12），本项目已经实现：

- 文档，剪贴板，陶片放逐保存；

- 用户多项历史保存；

- 用户犇犇保存；

- 讨论区保存（目前仅支持非题目板）；

- 插件广场；

- 题解修，方便地进行题解格式的修正；

- ~~比赛历史与比赛等级分预估~~；[^1]

- ~~题目保存，可显示能够提交题解的题目~~；[^1]

- 更多更多……



[^1]: 曾经实现过，但如今因 [洛谷官方要求](https://luogu.ac.cn/discuss/1368593)，这些内容因无法在新规下实现，已被暂时移除。
